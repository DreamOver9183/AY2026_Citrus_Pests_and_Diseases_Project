**基礎混淆矩陣元素定義**

- **真陽性（True Positive, TP）**：實際為陽性，模型正確預測為陽性。
- **真陰性（True Negative, TN）**：實際為陰性，模型正確預測為陰性。
- **偽陽性（False Positive, FP）**：實際為陰性，模型誤判為陽性（型 I 錯誤 / 虛警）。
- **偽陰性（False Negative, FN）**：實際為陽性，模型漏判為陰性（型 II 錯誤 / 漏報）。

---

**分類評估指標與 LaTeX 公式整理**

**1. Accuracy（準確率）**

- **定義說明**：衡量所有分類結果中判斷正確（無論陽性或陰性）的比例。適用於各類別樣本數相近的平衡資料集，作為模型品質的粗略基準。
- **數學公式**：

$$\text{Accuracy} = \frac{\text{correct classifications}}{\text{total classifications}} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}}$$

**2. Recall / True Positive Rate（召回率 / 真陽性率, TPR）**

- **定義說明**：又稱偵測機率（Probability of Detection），衡量所有「實際為陽性」的樣本中，被模型正確識別出的比例。在偽陰性（漏報）代價極高的任務中（如疾病診斷、重大缺陷檢測）為核心指標。
- **數學公式**：

$$\text{Recall (or TPR)} = \frac{\text{correctly classified actual positives}}{\text{all actual positives}} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

**3. False Positive Rate（偽陽性率, FPR）**

- **定義說明**：又稱假警報機率（Probability of False Alarm），衡量所有「實際為陰性」的樣本中，被模型誤判為陽性的比例。
- **數學公式**：

$$\text{FPR} = \frac{\text{incorrectly classified actual negatives}}{\text{all actual negatives}} = \frac{\text{FP}}{\text{FP} + \text{TN}}$$

**4. Precision（精確率）**

- **定義說明**：衡量所有「被預測為陽性」的樣本中，實際確實為陽性的比例。當偽陽性（誤報）會造成高昂成本或不良使用者體驗時（如垃圾郵件誤擋正常重要郵件），需優先最佳化此指標。
- **數學公式**：

$$\text{Precision} = \frac{\text{correctly classified actual positives}}{\text{everything classified as positive}} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$

**5. F1 Score（F1 分數）**

- **定義說明**：Precision 與 Recall 的調和平均數（Harmonic Mean），能有效綜合評估兩者的平衡表現。相較於 Accuracy，F1 Score 在類別不平衡資料集上具備更高的參考價值。
- **數學公式**：

$$\text{F1} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\text{TP}}{2\text{TP} + \text{FP} + \text{FN}}$$

---

**指標適用場景與權衡對照**

| 指標             | 核心關注點               | 最佳適用場景                                                       | 限制與注意事項                                                                          |
| ---------------- | ------------------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| **Accuracy**     | 整體預測正確率           | 類別平衡的資料集、初步評估基準                                     | **WARNING: 在高度不平衡資料集下會嚴重失真（例如 99% 負例時全猜負例仍有 99% 準確率）。** |
| **Recall (TPR)** | 盡可能抓出所有陽性       | 偽陰性（FN）代價高於偽陽性（FP）時（如癌症篩檢、安全入侵偵測）     | 追求高 Recall 通常會導致 Precision 下降（誤報增加）。                                   |
| **FPR**          | 壓低對陰性樣本的誤判     | 偽陽性（FP）代價極高且需控制虛警率時                               | 當實際陰性樣本極少時，指標易產生劇烈波動。                                              |
| **Precision**    | 確保預測為陽性的準確度   | 偽陽性（FP）代價高於偽陰性（FN）時（如自動封鎖帳號、垃圾郵件過濾） | 追求高 Precision 通常會導致 Recall 下降（漏報增加）。                                   |
| **F1 Score**     | 兼顧 Precision 與 Recall | 類別不平衡資料集，且兩者權重相當的場景                             | 若兩者數值差距過大，F1 分數會大幅偏向較差的那一項。                                     |

---

**極端數值說明**

> [!IMPORTANT]
> **NOTE: 關於指標計算出現 NaN（Not a Number）的成因**
> 當公式的分母為 0 時會產生 NaN。例如，若模型從未將任何樣本預測為陽性（$\text{TP} = 0, \text{FP} = 0$），計算 Precision 時分母為 0，結果即為 NaN。這通常代表模型在該分類閾值下無法有效做出正向判定。
