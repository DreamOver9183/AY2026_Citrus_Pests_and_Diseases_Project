### 4.2 公式定義與計算依據

1. **Accuracy（準確率）**：
   $$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}} = \frac{\text{TP} + \text{TN}}{N_{\text{total}}}$$
2. **Precision（精確率）**：
   $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$
3. **Recall / TPR（召回率 / 真陽性率）**：
   $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
4. **False Positive Rate（偽陽性率, FPR）**：
   $$\text{FPR} = \frac{\text{FP}}{\text{FP} + \text{TN}}$$
5. **F1 Score（F1 分數）**：
   $$\text{F1} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\text{TP}}{2\text{TP} + \text{FP} + \text{FN}}$$

## 5. 類別檢測瓶頸與誤差診斷 (Error Analysis & Bottlenecks)

### 5.1 優勢類別

1. **Sooty_Mold (煤煙病)**：Recall 達到 $100.00\%$，Precision $96.88\%$，AP@0.5 高達 $0.980$。主要因煤煙病呈大面積黑色斑狀紋理，與葉片背景對比強烈，無漏檢現象。
2. **Oily_Spot (油斑病)** 與 **Black_Spot (黑斑病)**：AP 分別達到 $0.978$ 與 $0.934$，F1 均高於 $85\%$，特徵提取穩定。

### 5.2 主要瓶頸與錯誤源分析

1. **Scale_Insect (介殼蟲) 的高偽陽性 (FP = 615)**：
   - 介殼蟲為樣本量最大類別（真實標註 $1,453$ 個，模型預測 $1,912$ 個）。
   - 其偽陽性率 FPR 達到 $39.30\%$，主要來自葉片上的微小反光點、灰塵或木栓化組織被誤判為介殼蟲，導致單類別 Accuracy 降至 $74.45\%$。
2. **Thrips (薊馬) 的高偽陰性 (FN = 106)**：
   - 薊馬 Recall 僅 $53.91\%$（AP@0.5 為 $0.572$），為全類別最低。
   - 混淆矩陣顯示 $104$ 處真實薊馬被漏檢（判定為背景），主因為薊馬體型極為微小且常隱匿於葉脈褶皺，P2 層特徵仍存在部分感受野邊界遺失。
3. **Thrips 與 Aphid 間的微量相互誤判**：
   - 混淆矩陣中薊馬與蚜蟲存在 $5$ 處相互誤判（$3$ 隻蚜蟲誤判為薊馬，$2$ 隻薊馬誤判為蚜蟲），源於兩者在低解析度下外觀長寬比與顏色具相似性。

## 6. 技術結論與後續改進建議 (Actionable Recommendations)

1. **推論置信度閾值設定**：
   - 依據 F1-Confidence 曲線，建議線上推論部署時將全域置信度閾值（Confidence Threshold）設定於 **$0.285$**，以取得 Precision 與 Recall 的最佳平衡（F1 = 0.79）。
2. **背景偽陽性抑制策略（針對介殼蟲）**：
   - 介殼蟲背景誤判高達 $615$ 例，可適度提高背景樣本（Background Images / Negative Samples）之採樣比例，或提高分類損失權重（`cls: 1.0 ~ 1.2`）以加強背景抑制。
3. **微小目標特徵加強（針對薊馬）**：
   - 針對薊馬漏檢問題，可評估微調輸入尺寸至 $800 \times 800$ 或在特徵金字塔融合段增強淺層注意力權重，改善極小目標召回率。
