## 為什麼 v8 的數字不能拿來比較

不只是「量尺不同」那麼簡單：

1. **影像洩漏。** v5 與 v5r 是各自獨立重新切分的，感知雜湊比對顯示
   **v5r 的 valid 有 44.5%、test 有 47.5% 的影像出現在 v5 的訓練集中**。
   拿 v8 的權重去驗 v5r，等於在它訓練過的影像上評分。
   **不存在一份能公平評估 v8 的 v5r 資料。**
2. **標註約定改變。** v5r 重整了 Thrips 與 Aphid 的標註尺度
   （邊長極差由 24.7x／26.0x 降至 9.1x／9.4x），框的定義本身變了。
3. **取法不同。** v8 報告引用的 82.08% 是 50 輪平台期（80.38% ± 0.69%）的抽樣最大值，
   不是能力估計。

現行專案唯一合法的對照基準是重訓的 A0。
完整說明見 [../v9_報告_v10之前的技術總結.md](../v9_報告_v10之前的技術總結.md) §8。
